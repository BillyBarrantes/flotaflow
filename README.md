# FlotaFlow

Sistema integral de gestión de flotas, logística y operaciones de transporte, impulsado sobre arquitectura modular y gobernanza agéntica.

## Módulos Principales
- **API Core:** Backend transaccional y enrutamiento logístico.
- **Console:** Panel de control web para despachadores y administradores.
- **Agentic Ops:** Control plane para mantenimiento, auditoría y extensiones automatizadas.
